# GestionFarmaSalud

Proyecto de Gestion de la farmaSalud codeable hecho en C, se manejan elementos importantes y centrales de una farmacia donde se muestra en un menu cada opcion que es manejable dentro de una farmacia, por tanto abrir el main.c que se encuentra en el zip en algún IDE con lenguaje C y ejecutarlo, el sistema se encuentra sin datos por lo que si quieres modificar, borrar o buscar a alguien primero debes agregarlo a la base del sistema.
